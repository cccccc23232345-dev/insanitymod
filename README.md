# Alcohol Mod

Dont mind files being called insanity mod. Was originally gonna be a mod where you have to drink alcohol to not go insane but became too complicated for me.

## How it works

*All alcohol*ic drinks are craftable using in game items. Current default recipe is: Glass bottle, sugar and special item for each drink. Figure it out yourselves. Currently, there's a bug that makes it so when you respawn after death from alcohol poisoning you instantly get status effects after one drink instead of the normal two.
